How it scores

12 engineered signals amount, hour, payee age, distance, velocity…
Normalize to 0-1 so weights are comparable
Logistic regression + L2 → fraud probability
Factor contributions weight × signal value

Every score decomposes into per-factor contributions — the same linearity that makes this model auditable is what real fraud teams use for first-pass triage.

Ships with pre-trained weights for instant, deterministic results.

Honest limits: trained on 1,200 synthetic transactions with deliberately injected fraud patterns (big amounts, odd hours, new payees, far distances, bursts). The metrics describe performance on that synthetic data only — real fraud is subtler, adaptive and nothing like a clean rule set. This is a teaching tool, not a bank-grade system.
